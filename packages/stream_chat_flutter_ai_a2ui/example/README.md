# A2UI gallery

A gallery of the examples published with A2UI's basic catalog, and of the Ohrid trip example the Stream agent backend
gives its model, drawn with `stream_chat_flutter_ai_a2ui`'s components in light and dark.

Examples that use components the package doesn't draw yet say which. "Replay" writes an example message by message, as
an agent streams it, so components come in as they arrive. Below an example, the gallery lists what a person's actions
in it did: each event an agent would get, with its values, and each link that would open.

```bash
flutter run
```
